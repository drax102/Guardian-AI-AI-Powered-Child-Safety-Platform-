# 🛡 GuardianAI — AI Powered Child Safety Platform

## Overview

GuardianAI is a cloud-native child safety platform designed to monitor and visualize safety incidents using secure cloud infrastructure.

The platform captures incidents, stores evidence securely, and provides a dashboard for monitoring.

---

## Problem Statement

Parents often lack visibility into unsafe digital and physical environments.

GuardianAI aims to provide:

- Incident tracking
- Image-based alerts
- Secure cloud storage
- Monitoring dashboard
- Scalable architecture

### Frontend

```bash

npm run dev
```

### Backend

```bash

pip install -r requirements.txt

uvicorn main:app --reload
```
